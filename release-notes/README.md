## Frequently Asked Questions

### Which Aspose.Imaging for .NET release improved AVIF processing performance and reduced memory load?  
The performance and memory improvements for AVIF processing were shipped in the **26.10** release – see the examples in the [26.10](./26-10/README.md) folder.

### Which release added proper checking for TIFF file support, including XIF?  
Support for proper TIFF (and XIF) file validation was introduced in the **26.10** release – see the related code in the [26.10](./26-10/README.md) folder.

### In which release was the inconsistent metadata removal issue for TIFF fixed?  
The fix for inconsistent metadata removal from TIFF files (exposing metadata properties beyond Exif and Xmp) was delivered in the **26.10** release – see the examples in the [26.10](./26-10/README.md) folder.

### What new APIs were introduced in the 26.10 release?  
The **26.10** release added the following APIs: `Aspose.Imaging.Exif.ExifData`, `Aspose.Imaging.ImageFilters.FilterOptions.BlendingMode`, `Aspose.Imaging.ImageFilters.FilterOptions.ConvolutionFilterOptions`, and `Aspose.Imaging.ImageFilters.FilterOptions.ImageBlendingFilterOptions` – see the sample code in the [26.10](./26-10/README.md) folder.

### Where can I find the C# example code for the features shipped in the 26.10 release?  
All C# examples for the 13 new or updated features in the **26.10** release are located in the [26.10](./26-10/README.md) folder of this repository.
